# Rollout Application Configuration Guide
 
The **Settings** screen provides a central place to configure the main providers and platform behavior used by the Rollout Application.

From this page, you can review setup progress, check configuration status, and open each section in either **View** or **Edit** mode.

The Settings screen is organized into the following configuration areas:
 
- [Issue Management](/rolloutapplication/config/issue/Issue%20config.md)
- [Version Control](/rolloutapplication/config/version/version%20config.md)
- [Rollout Package Configuration](/rolloutapplication/config/rollout_config.md) 
- [System Configuration](/rolloutapplication/config/system_config.md)
- [Authentication](/rolloutapplication/config/auth/Auth%20config.md)

Each card displays its current setup summary, including:

- configuration status such as **Configured**
- the number of configured items
- completion percentage
- quick actions for **View** and **Edit**

The available cards in the current UI are:

- **Issue Management**
- **Version Control**
- **Rollout Package**
- **System**
- **Authentication**
